# report/: the written report

`report.Rmd` is the outline. Each section says what goes in it and which notebook its numbers come from. Fill it in once the findings in `analysis/` are written.

## Suggested structure

1. **Introduction:** the central question and why it matters
2. **What's already known:** Preston curve, Wilkinson & Pickett vs Deaton, Avendano (2012), Leigh, Good Health at Low Cost, "punching above their weight"
3. **What we add:** global sample, recent data (2000s → 2010s), several explanations compared, interactive app
4. **Data and methods**
5. **Results:** wealth → inequality → spending → foreign money → wellbeing → institutions
6. **Over time**
7. **Beating expectations**
8. **Forecasts and model comparison**
9. **Conclusion, limitations, next steps**
10. **References**

## Rules

- **Check every citation against the original paper** (author, year, journal, finding) before using it. Several were suggested from memory or search results.
- Use the same numbers as the app: copy them from the notebooks, don't recompute differently.
- Association language throughout ("is linked to", not "causes").
- If your course requires it, add a short note on how AI assistance was used.
